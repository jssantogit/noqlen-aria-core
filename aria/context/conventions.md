# Conventions

- Use Python 3.11+.
- Keep public documentation in English.
- Keep dependencies minimal.
- Keep commits small and focused.
- Use a thin CLI only for safe local development diagnostics.
- Prefer structured, explicit results at product boundaries.
- Avoid unrelated refactors.
- Do not invent business rules.
- Do not add Anchor as a dependency in Bloco 0.
- Do not add Android, Kotlin, or Gradle dependencies in Bloco 0.
- Validate after changes and record evidence.
