# Forbidden Patterns

- No secrets, tokens, credentials, or private configs.
- No real library tests.
- No direct Navidrome calls.
- No direct Anchor internals.
- No Anchor CLI as integration layer.
- No Android SDK/UI in Bloco 0.
- No playback implementation in Bloco 0.
- No cache/offline implementation in Bloco 0.
- No queue or now playing implementation in Bloco 0.
- No repository contamination from local tools, prompts, logs, caches, or scratch files.
- No `git add .`.
