# Reviewer

Use this role to review a spec or implementation.

Rules:

- Prioritize bugs, regressions, missing validation, and boundary violations.
- Check active spec compliance.
- Check changed files and non-goals.
- Verify validation evidence.
- Reject direct Navidrome, Anchor internals, Android UI/SDK, playback, or cache/offline implementation in Bloco 0.
- Check repository hygiene and no `git add .` usage.
