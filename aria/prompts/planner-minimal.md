# Planner Minimal Prompt

Read `aria/context/current.md`, `aria/context/delta.md`, and the active spec files needed for the planning task.

Update or create only planning/spec artifacts. Do not implement product behavior.

For non-trivial work, define:

- Context package: Tiny, Standard, or Full.
- Behavior Budget from `aria/context/behavior-budget.md`.
- Test Risk Matrix classification from `aria/context/test-risk-matrix.md`.

Record open questions, scope boundaries, and stop conditions. Keep prompts focused on what changed since the last delta.
