# Implementer Minimal Prompt

Read `aria/context/current.md`, the active task, target files, and target tests. Use the smallest package from `aria/context/context-packages.md` that can safely complete the task.

Implement one task only.

Stay within the Behavior Budget. Stop if scope, files, dependencies, or behavior exceed the budget.

Update `aria/context/delta.md` and the active `review.md` when the task requires recorded evidence.

Run proportional validation, record the evidence, and stop. Do not start the next task.
