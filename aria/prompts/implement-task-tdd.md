# Implement Task TDD Prompt

Implement exactly one task test-first when practical.

Steps:

- Add or update the smallest failing test.
- Implement the smallest production change.
- Run focused validation.
- Run broader validation required by the spec.
- Record evidence.

Tests must not require network, real music libraries, Anchor, Navidrome, Android, playback, or cache/offline behavior in Bloco 0.
